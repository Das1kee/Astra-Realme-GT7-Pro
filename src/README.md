# Astra

> 为 Realme GT7 Pro（RMX5010 / ColorOS 17）定制的模块：温控 · 电池 · 调度。
> 作者 Dasikee · dasikee@qq.com

## 温控

- **官方温控**（默认）：零干预，开机清空所有 `emul_temp`。
- **GT去温控**：bind mount 替换厂商温控策略表，保留全部策略等级并清掉表内 CPU/GPU 软频率上限；硬件过温保护保留，**建议重启一次**。
- **温度伪装**：`emul_temp` 写 26.6℃ ±0.4℃（180s 周期），只接管壳温 / `sys-therm-*` 等皮肤热区；`socd` 与射频/调制解调器热区一律不写——写入毫摄氏度会被固件判成极端过温并掉信号。
  - 真实温度从 `power_supply` 读，不受伪装影响。
  - 「拉高真实温控墙」：两条熔断线整体 +3℃。
  - 熔断：真实电池 ≥45℃ 或 SoC ≥95℃ → 立即交还官方，降温 5℃ 恢复。

## 充电

- 充电功率只在真正充电时显示；未充电 / 已充满显示 0.0 W。USB 输入节点不刷新时退回电池侧（整组电压）估算。
- 满血充电只解除模块自己写入的输入限流，不绕过厂商快充握手、亮屏降速与温控策略。
- 温度保护线；到达保护线或电量 90% 时交还官方阶梯充电。

## 调度

- **官调限频**：写 `msm_performance/parameters/cpu_max_freq` 与各 `cpufreq` policy，每轮回读确认。
- **自动让出**：游戏中 / Scene 接管当前前台应用时，立即恢复官方上限。
- **GPU Boost**：独立开关；官调限频开启时强制禁用。
- **调度统计**：当前功耗、30 秒平滑平均功耗、最近三款应用的时长 / 耗电 / 平均功耗。
- **深度睡眠**：Android Doze；亮屏、充电、通话或音乐播放立即退出。

## 安装 / 卸载

1. 从 Releases 下载最新 ZIP → SukiSU → 模块 → 从本地安装
2. **重启**
3. SukiSU → 模块 → Astra → 打开 WebUI

卸载：管理器删除模块 → 重启。会还原温度仿真、legacy 挂载、充电节点、CPU 上限、GPU 最低频、厂商属性，并删 `/data/adb/Astra`。
