# Astra · Beta0.1.11

> 为 Realme GT7 Pro 定制的模块，功能为温控·电池·调度相关。私人定制切勿分享。
> 作者 Dasikee · dasikee@qq.com

## 0.1.11 改了什么

| 反馈 | 处理 |
|---|---|
| 当前功耗应带符号 | **充电 +x.xx W，放电 -x.xx W** |
| 平均功耗要 Scene 同款 | 改为**本次放电会话的平均**（`本次放电累计 µAh ÷ 放电时长`，插电即重置），不再是"总放电 ÷ 总在电池时间" |
| 删掉耗电详情 / 放电速率 | 已删除 |
| 最近应用只要四项 | **名称 / 使用时长 / 耗电 mAh / 该应用使用时的平均功耗**；去掉了图标和占比条 |

应用数据现在是真采样：守护进程每 30 秒把「前台包 + 这段时间库仑计掉电」累加进 `usage.db`，所以每个应用的 mAh 和平均功耗是独立实测的；刚装上时用当前平均电流估算，跑一会儿就会替换成实测值。

## 0.1.10 改了什么

| 反馈 | 处理 |
|---|---|
| 平均功耗一直 0.41W，跟 Scene 不一样 | 根因有两个：① 本机 `current_now` 是**单电芯 mA**，双电芯要 ×2（Scene 自己的配置里就写着 `rmx5010_current_double=true`）；② 之前的 0.41W 是 `batterystats` 的「总放电 ÷ 总在电池时间」，把 17 小时息屏摊进去了。现在改用**库仑计 `charge_counter` 差值**算真实电流（与节点单位无关），平均功耗为**放电期间的滑动平均**，充电时清零、下次放电重新统计 |
| 要看得懂耗电 | 耗电统计卡新增 **当前功耗 / 放电速率**；下面新增 **耗电详情（系统统计）**：自上次充电用了多少 mAh、亮屏/息屏时长、系统平均电流，作为对照基准 |

实测（当前正在充电）：

- 当前功耗 **2.38 W**（USB 输入侧）
- 放电速率 **—**（充电中）
- 耗电详情：自上次充电 **2547 mAh** / 亮屏 **8h36m** / 息屏 **17h31m** / 系统平均电流 **97 mA**
- 库仑计标定：60 秒 `charge_counter` +6000 µAh → **+360 mA**，与 `current_now -183 × 2`（双电芯）吻合

## 0.1.09 改了什么

| 反馈 | 处理 |
|---|---|
| 未充电时剩余电量不准 | 改为 **百分比 × 满充容量**（`capacity × charge_full / 100`），充电 / 放电都准；mAh 先试 charge_now、charge_counter 兜底 |
| Scene 开关没用 | **删除**「Scene 显示伪装温度」；旧版可能残留的 `battery/temp` 挂载会在开机与每次 tick 自动清掉 |
| 伪装温度要自动浮动 | 默认 **±0.4℃ / 180 秒一个周期**（可在 config 里改 MASK_AMP / MASK_PERIOD） |
| 省电限频改名 | → **官调限频** |
| 官调限频与 Scene 冲突 | 新增**自动让出**：Scene 在跑、且给当前前台应用下发过功耗模式（`powercfg.xml`）时，模块立刻释放频率上限，状态显示「Scene 接管」；游戏时同样暂停 |
| 耗电统计太多、页面卡 | 上限 **3 条**；平均功耗改由**后台每 10 分钟**折算一次，页面打开不再现场跑 dumpsys |
| 设置说明不清楚 | 说明改为：GT去温控建议重启一次（让厂商服务重读策略表），温度伪装无需重启；并写明与 Scene 的让出逻辑 |

---

## 三种模式

- **官方温控**（默认）：零干预，开机清空所有 `emul_temp`。
- **GT去温控**：bind mount 替换厂商温控表（策略表 + 高温软降级），硬件关机保护保留；**建议重启一次**。
- **温度伪装**：`emul_temp` 写 26.6℃ ±0.4℃（180s 周期），接管壳温 / socd / sys-therm；真实温度从 `power_supply` 读，不受伪装影响。
  - 「拉高真实温控墙」：两条熔断线整体 +3℃。
  - 熔断：真实电池 ≥45℃ 或 SoC ≥95℃ → 立即交还官方，降温 5℃ 恢复。

---

## 调度

- **官调限频**：走 `msm_performance/parameters/cpu_max_freq`，每 4 秒重压一次（perf HAL 会回抬）。
- **自动让出**：游戏中 / Scene 接管当前前台应用时，立即恢复官方上限。
- **GPU Boost**：独立开关；官调限频开启时强制开。
- **耗电统计**：最多 3 条，名称 + 占比条 + mAh + 时长；右上角平均功耗（batterystats 折算，后台刷新）。

---

## 安装 / 卸载

1. `Astra-Beta0.1.09.zip` → SukiSU → 模块 → 从本地安装
2. **重启**
3. SukiSU → 模块 → Astra → 打开

卸载：管理器删除模块 → 重启。会还原温度仿真、legacy 挂载、充电节点、CPU 上限、GPU 最低频、厂商属性，并删 `/data/adb/Astra`。
